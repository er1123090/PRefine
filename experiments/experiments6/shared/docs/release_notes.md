# Release Notes

- This folder is a refactored public release derived from `/data/minseo/experiments4`.
- `experiments4` and `experiments5` are not edited by the release construction.
- `e-mem` is intentionally excluded.
- Generated outputs, logs, vector stores, bytecode caches, nested git repositories, and virtualenvs are intentionally excluded.
- Legacy top-level symlinks are provided so old run commands can still resolve the original directory names.
